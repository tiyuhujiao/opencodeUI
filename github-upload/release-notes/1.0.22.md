# opencode-ui 1.0.22

本版本把 `1.0.6` 之后累积的开发内容一次性发布，最重要的是完整支持 OpenCode v2 服务 API。

## OpenCode v2 支持

- 运行时自动识别 v1（`/global/health`）与 v2（`/api/info`）：v2 使用 Basic Auth，受管 `opencode serve` 会自动生成 `OPENCODE_PASSWORD`，密码写入 VS Code SecretStorage 并可在扩展宿主重启后复用。
- v2 适配覆盖 session 创建/列表/历史、异步 prompt 与 Queue、agent 与 model 切换、commands、interrupt、fork、revert、diff、export、permission、question form、provider/model/integration、API key 与 OAuth、agents、skills、MCP 以及 `/api/event` 事件流。
- 修正 v2 运行时缺口：排队中的斜杠命令改由服务端生成的消息 ID 认领；非 question 表单（`websearch.provider`、`mcp-elicitation` 等）同样以问题面板呈现，不可回答的表单自动取消；错误正文改为可读信息；重试步骤不再重复渲染；SSE 断流按 `/session/status` 正常收尾而不是直接判失败。
- v2 Provider 设置同时支持旧版 `provider/{npm,options}` 与原生 `providers/{package,settings}`，保留 JSONC 注释与未知字段，API key 与敏感请求头继续屏蔽。

## 侧边栏体验

- 新增当前对话搜索（匹配计数、大小写/全字/正则、上下匹配切换）与历史会话搜索（会话标题/ID + 当前项目全部消息正文，命中词高亮并可滚动定位）。
- Queue 与同一次运行共享唯一计时分组，续写不再被显示成新一轮。
- 内联 Diff 在每个编辑工具完成后立即串行打开 VS Code 原生 Diff；折叠活动块摘要按真实事件顺序在 Tool/Thinking 之间切换。
- Markdown 表格在窄侧栏中不再撑破布局，保留表头底色、完整分隔线与可聚焦横向滚动。
- 恢复并完善 macOS 本机、Remote-SSH macOS 与通用 macOS 远端支持；README 中英文同步说明支持平台。

## 稳定性

- `opencode serve` 启动失败或数据库锁定的瞬时错误在服务恢复后自动清除，不再残留红框。
- 非 ASCII 工作目录（例如中文路径）与 Windows 跨盘工作区的会话路径不一致问题已修复。

# opencode-ui 1.0.22

This release ships everything accumulated since `1.0.6`, and the headline change is full support for the OpenCode v2 server API.

## OpenCode v2 support

- The extension detects the server API at runtime: v1 through `/global/health`, v2 through `/api/info`. v2 uses Basic Auth, and a managed `opencode serve` generates `OPENCODE_PASSWORD` automatically; the password is stored in VS Code SecretStorage and reused after the extension host restarts.
- The v2 adapter covers session create/list/history, async prompts and Queue, agent and model switching, commands, interrupt, fork, revert, diff, export, permission, question forms, provider/model/integration, API keys and OAuth, agents, skills, MCP, and the `/api/event` stream.
- v2 runtime gaps are fixed: queued slash commands adopt the server-generated message ID; non-question forms (`websearch.provider`, `mcp-elicitation`, and friends) render as question panels while unanswerable forms cancel themselves; error bodies become readable text; retried steps no longer duplicate; and an interrupted SSE stream falls back to `/session/status` instead of failing the whole run.
- Provider settings accept both the legacy `provider/{npm,options}` shape and the native `providers/{package,settings}` shape, preserving JSONC comments and unknown fields while still masking API keys and sensitive headers.

## Sidebar experience

- New search for the current conversation (match counter, case/whole-word/regex, next and previous match) and across historical sessions (session title or ID plus every message body in the project, with highlighted matches that scroll into view).
- Queue replies share a single timing group with the run that produced them instead of looking like a new turn.
- Inline diffs open the native VS Code diff right after each editing tool completes, and collapsed activity summaries pick the real last event between Tool and Thinking.
- Markdown tables stay inside a narrow sidebar, keeping header tint, full separators, and focusable horizontal scrolling.
- macOS local, Remote-SSH macOS, and generic macOS remote hosts are supported again, with the bilingual README updated to match.

## Stability

- Transient `opencode serve` startup or database-lock errors clear automatically once the server recovers instead of leaving a stale error banner.
- Non-ASCII workspace directories and Windows cross-drive workspaces resolve a consistent session directory.
