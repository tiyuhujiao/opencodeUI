## opencode-ui 0.0.2

将 OpenCode serve 运行生命周期抽取为独立模块，并建立本地开发版本与 GitHub 公共版本分离的打包流程。

### 更新内容

- 将 OpenCode serve 运行生命周期从 `SidebarProvider` 抽取到独立 `runLifecycle` 模块，降低侧边栏 provider 的职责负担。
- 保持现有 Webview 消息协议不变，同时集中处理 serve event 分发、permission/question blocker 轮询去重、子 session 归属判断和流式增量转换。
- 更新回归测试，让测试直接覆盖新的 run lifecycle 公共接口，并修正停止运行事件的顺序保护断言。
- 本次 GitHub 对外 Release 版本为 `0.0.2`，本地开发/安装版本继续使用 `0.0.76`。

本 Release 资产 `opencode-ui-0.0.2.vsix` 构建自本地版本 `0.0.76`。

## opencode-ui 0.0.2

Extracted the OpenCode serve run lifecycle into a focused module and established separate local-development and GitHub public-version packaging.

### Changes

- Extracted the OpenCode serve run lifecycle from `SidebarProvider` into the standalone `runLifecycle` module, reducing the sidebar provider's responsibilities.
- Kept the existing Webview message protocol unchanged while centralizing serve-event dispatch, permission/question blocker polling deduplication, child-session ownership, and streaming-delta conversion.
- Updated regression tests to cover the new public run-lifecycle interface directly and corrected stop-event ordering assertions.
- Set the GitHub public Release version to `0.0.2` while keeping local development/install version `0.0.76`.

The `opencode-ui-0.0.2.vsix` asset in this Release was built from local version `0.0.76`.
