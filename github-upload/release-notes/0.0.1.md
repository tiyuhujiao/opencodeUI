## opencode-ui 0.0.1

首次公开发布 opencode-ui，建立独立的 GitHub 公共版本线。

### 更新内容

- 初始化 opencode-ui 的公开 GitHub 仓库，保留可阅读源码、README、许可证和安全反馈入口。
- 发布首个公开 VSIX 安装包，方便从 GitHub Releases 下载并安装。
- 公开版本从 `0.0.1` 开始；该公开包基于本地开发/安装版本 `0.0.75` 生成。

本 Release 资产 `opencode-ui-0.0.1.vsix` 构建自本地版本 `0.0.75`。

## opencode-ui 0.0.1

First public opencode-ui release with an independent GitHub version line.

### Changes

- Initialized the public opencode-ui GitHub repository with readable source, README files, the license, and a security feedback entry point.
- Published the first public VSIX package for download and installation from GitHub Releases.
- Started the public version line at `0.0.1`; this package was built from local development/install version `0.0.75`.

The `opencode-ui-0.0.1.vsix` asset in this Release was built from local version `0.0.75`.
