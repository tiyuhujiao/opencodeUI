## 中文

- 正式支持 Apple Silicon 与 Intel Mac，包括本机 macOS 和 Remote-SSH macOS。
- 补全 Homebrew、MacPorts、npm、Bun、pnpm、Yarn、Mise 等 OpenCode CLI 自动发现路径，改善从 Finder 启动 VS Code 时的兼容性。
- GitHub Actions 增加 Windows、Linux、macOS 三平台验证，并在 macOS 运行真实 VS Code 扩展烟测。

## English

- Added first-class support for Apple Silicon and Intel Macs, including local macOS and Remote-SSH macOS hosts.
- Expanded automatic OpenCode CLI discovery for Homebrew, MacPorts, npm, Bun, pnpm, Yarn, and Mise, including VS Code sessions launched from Finder.
- Added Windows, Linux, and macOS CI validation with a real VS Code extension smoke test on macOS.
